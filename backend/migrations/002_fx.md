# 002 境外费用折算

新增业务表：`fxquotes`（汇率报价，JSON：date/base/quote/rate）、`fxexpenses`（境外费用底稿，JSON：date/voucher/department/category/currency/amount_minor）；`allocationruns` 增加 `kind` 列区分旧人民币报告（cost）与折算报告（fx）。

应用启动与 worker 启动时执行 `ensure_schema()`：`create_all` 建齐新表，并执行幂等列演进：

```sql
ALTER TABLE allocationruns ADD COLUMN IF NOT EXISTS kind VARCHAR(20) NOT NULL DEFAULT 'cost';
```

既有报告自动落入 `kind='cost'`，旧人民币报告照常查看；已有数据库升级前请先备份。
